Ember Duel — an original three-lane card battler built for make.fun's "Make the best card game" bounty. Four elemental suits (Ember, Tide, Stone, Gale), energy-limited turns, suit combo bonuses and a Trinity bonus for playing three different suits in one turn, against a rival whose intents are shown face-up so every turn is a counter-play decision. Runs offline in a desktop browser from static files under `game/`, playable with mouse and keyboard.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
